# PrayTeamView

같은 팀원이 어디 있는지 화면에 보여주는 마인크래프트 Fabric 모드입니다. 벽 너머에 있든 한참 떨어져 있든, 팀원 위치를 놓치지 않게 해줍니다.

클라이언트에만 설치하면 되고, **1.20.1 · 1.21.1 · 1.21.11** 을 지원합니다.

## 무엇이 보이나요

**팀원 머리 위 마커**

팀 색상으로 된 `▼` 표시가 팀원 머리 위에 뜹니다. 블록에 가려져 있어도 보이기 때문에 건물 안이나 지하에 있는 팀원도 바로 찾을 수 있습니다. 멀리 있는 팀원은 이름과 거리(`(320m)`)까지 같이 표시됩니다.

**화면 위쪽 방향 표시줄**

화면 상단 나침반 띠에 팀원 얼굴이 나타나 어느 쪽에 있는지 알려줍니다. 시야 밖에 있는 팀원은 화면 좌우 끝에 붙어서 방향만 가리킵니다.

## 이런 경우엔 표시되지 않습니다

- 팀원이 다른 차원(네더, 엔드 등)에 있을 때
- 팀원 정보가 몇 초간 갱신되지 않았을 때 (접속 종료 등)
- 너무 멀리 떨어져 있을 때
- <kbd>F1</kbd> 로 화면 표시를 껐을 때

## 설치

1. 아래 표에서 자신의 마인크래프트 버전에 맞는 것을 확인하세요.
2. [릴리스](../../releases)에서 `prayteamview-<모드 버전>+<마인크래프트 버전>.jar` 를 받습니다.
3. **Fabric API** 와 함께 `.minecraft/mods` 폴더에 넣습니다.

| 마인크래프트 | 받을 파일 | Fabric Loader | Java |
|---|---|---|---|
| 1.20.1 | `...+1.20.1.jar` | 0.16.14 이상 | 17 이상 |
| 1.21.1 | `...+1.21.1.jar` | 0.19.5 이상 | 21 이상 |
| 1.21.11 | `...+1.21.11.jar` | 0.19.5 이상 | 21 이상 |

서버에 Pray TeamView 기능이 있어야 동작합니다. 지원하지 않는 서버에서도 접속은 정상적으로 되며, 팀원 표시만 나타나지 않습니다.

## 아무것도 안 보인다면

- 마인크래프트 버전에 맞는 파일을 받았는지 확인해 주세요.
- Fabric API 가 함께 설치되어 있어야 합니다.
- 팀에 속해 있고, 팀원이 나와 같은 차원에 접속해 있어야 합니다.
- 서버가 이 기능을 지원하지 않으면 아무것도 표시되지 않습니다.

## 설정 바꾸기

`.minecraft/config/prayteamview.json` 파일을 수정한 뒤 게임을 다시 시작하면 반영됩니다. 파일이 없다면 모드를 한 번 실행하면 기본값으로 만들어집니다.

| 항목 | 설명 | 기본값 |
|---|---|---|
| `enabled` | 모드 사용 여부 | `true` |
| `screenMarkers` | 팀원 머리 위 마커 표시 | `true` |
| `directionHud` | 화면 위쪽 방향 표시줄 | `true` |
| `distantDetailsDistance` | 이름과 거리를 함께 보여주기 시작하는 거리 (블록) | `64.0` |
| `maxRenderDistance` | 마커를 표시할 최대 거리 (블록) | `4096.0` |
| `snapshotTtlMillis` | 갱신이 끊긴 팀원을 지우기까지 기다리는 시간 (밀리초) | `3000` |
| `remoteInterpolationMillis` | 멀리 있는 팀원이 부드럽게 움직이는 정도 (밀리초, `0`이면 끊어서 이동) | `1000` |
| `teleportSnapDistance` | 이 거리 넘게 순간이동하면 부드러운 이동 없이 바로 옮김 (블록) | `32.0` |

## 직접 빌드하기

```bash
./gradlew build
```

세 버전이 한 번에 빌드되며, 결과물은 `versions/<마인크래프트 버전>/build/libs/` 에 생성됩니다.
